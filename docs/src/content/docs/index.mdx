<section>
<span class="section-marker">§ The problem</span>

## Retrieval is not memory.

Vector search gets you the closest match. It doesn't tell you what's *important*, what's *current*, or what should *fade*. Old facts compete with fresh ones. Trivial chatter outranks the allergy you mentioned six months ago.

Cognitive Memory is the missing middle: what happens to a memory after it's stored and before it's retrieved.

</section>

<span class="section-marker">§ Three ideas</span>

### 01. Memory is a lifecycle.

Write, maintain, retrieve, reinforce, fade, consolidate. Each stage has knobs.

<Figure number="1" caption="The lifecycle of a memory.">
  <MemoryLifecycle />
</Figure>

### 02. Forgetting is control.

Memories fade to an explicit floor before they leave the hot index. The 0.02 floor keeps a six-month-old fact recoverable when the right cue arrives. Core memories floor at 0.60 and stay strong.

<Figure number="2" caption="Retention over 180 days. Both floors are explicit.">
  <DecayCurve />
</Figure>

### 03. Important earns it.

Memories aren't just tagged at extraction. They earn protected status by being accessed often, across multiple sessions, with high stability. Use proves importance.

</section>

<span class="section-marker">§ Code</span>

## Two voices, one shape.

<Tabs syncKey="lang">
  <TabItem label="Python">
    ```python
    from cognitive_memory import CognitiveMemory, MemoryCategory

    mem = CognitiveMemory(user_id="alice")

    await mem.add(
        "Alex is allergic to peanuts",
        category=MemoryCategory.CORE,
        importance=0.95,
    )

    response = await mem.search("food allergies?")
    for r in response.results:
        print(r.memory.content, r.combined_score)
    ```
  </TabItem>
  <TabItem label="TypeScript">
    ```typescript
    import {
      CognitiveMemory,
      InMemoryAdapter,
      HashEmbeddingProvider,
    } from "cognitive-memory";

    const mem = new CognitiveMemory({
      adapter: new InMemoryAdapter(),
      embeddingProvider: new HashEmbeddingProvider(),
      userId: "alice",
    });

    await mem.store({
      content: "Alex is allergic to peanuts",
      category: "core",
      importance: 0.95,
    });

    const { results } = await mem.search({ query: "food allergies?" });
    for (const r of results) {
      console.log(r.memory.content, r.combinedScore);
    }
    ```
  </TabItem>

<div class="whats-new">
  <div>
    <strong>Tuned defaults</strong>
    <p>v0.5 moves associative boost to <code>0.05</code>, semantic decay to <code>240</code> days, and core-session threshold to <code>2</code>.</p>

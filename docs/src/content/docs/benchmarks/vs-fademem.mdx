## What this comparison says

FadeMem is important because it takes forgetting seriously. It moves beyond static vector memory by adding temporal decay. Cognitive Memory builds on a similar intuition but treats decay as one part of a larger lifecycle: reinforcement, associations, cold storage, deep recall, and consolidation.

Under the cited LoCoMo protocol, Cognitive Memory scores higher overall. The multi-hop number shown for Cognitive Memory uses the later corrected category mapping from the current-refresh artifact; it is useful context, not a same-codebase head-to-head.

## Architectural difference

FadeMem focuses on fading memory over time. Cognitive Memory adds:

- retrieval-based strengthening, so recalled memories can become more stable
- association links, so related memories can travel together
- core promotion, so frequently used cross-session facts get protected
- hot/cold/stub tiers, so normal search stays cleaner
- deep recall, so cold and superseded originals can be searched when exact details matter
